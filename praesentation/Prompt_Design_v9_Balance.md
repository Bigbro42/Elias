## 1. Layout rule for all slides: "optical balance"

For every slide, the **content area** is the space between the bottom edge of the headline (or the headline line) and the top edge of the source line.

1. **Centre the content block vertically** in that area. The gap from the headline to the content and the gap from the content to the source line should be about the same; at most 10 % difference.
2. **Even internal spacing:** the same distance between the rows, cards and elements of a slide (e.g. timeline → texts → takeaway line).
3. **Align with partners:** where a graphic and a list sit side by side, the list is centred vertically on the graphic. Top edge and bottom edge of the list should be the same distance from the top and bottom of the graphic.
4. **Use the space:** where a lot remains empty, scale the content up moderately (cards, icons, text +1–2 pt) instead of leaving the space blank. Do not add new content.
5. **Takeaway lines** (e.g. "Each phase added a capability…") sit at a fixed distance below the graphic, not pinned to the bottom edge.

**Measurable grid** (16:9, 33.87 × 19.05 cm):

| Element | Value |
|---|---|
| Side margins | 1.6 cm left and right |
| Kicker | top edge at 1.0 cm |
| Headline | top edge at 1.5 cm; same size on all content slides |
| Content area | from 3.6 cm to 17.2 cm (height 13.6 cm); the content block centred vertically in it |
| Source line | top edge at 17.9 cm |
| Spacing | only steps of 0.4 / 0.8 / 1.2 / 1.6 cm between elements; the same step within a slide |
