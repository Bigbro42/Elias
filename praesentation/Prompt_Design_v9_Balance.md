## 1. Terms in this prompt

| Term | Definition |
|---|---|
| Content area | The area between the bottom edge of the headline and the top edge of the source line. |
| Content block | All elements in the content area of one slide. |
| Takeaway line | The one line with the main message of a slide. |
| Label card | A small box with text that identifies a point on a map. |

## 2. Layout rules for all slides

### 2.1 Grid (slide size 33.87 × 19.05 cm)

| Element | Value |
|---|---|
| Left and right margin | 1.6 cm |
| Kicker, top edge | 1.0 cm |
| Headline, top edge | 1.5 cm |
| Content area | 3.6 cm to 17.2 cm |
| Source line, top edge | 17.9 cm |
| Spacing between elements | 0.4 cm, 0.8 cm, 1.2 cm or 1.6 cm |

### 2.2 Procedure

1. Put the content block in the vertical centre of the content area.
2. Make the space above and below the content block equal. The maximum difference is 10 %.
3. Use one spacing value between all elements of one slide.
4. If a list is adjacent to a graphic, align the two vertical centres.
5. If much of the content area is empty, make the cards, icons and text larger. Increase the text by 1 pt to 2 pt.
6. Do not add new content.
7. Use the same headline size on all content slides.

### 2.3 Takeaway line

1. Use one takeaway line on each content slide.
2. Use this style: serif, bold, 20 pt, centred.
3. Put the takeaway line 0.8 cm below the content block.
4. On slides 10, 14 and 15, replace the dark band with a takeaway line.
5. On slide 14, keep the "CONTEXT" line. Put it below the takeaway line as a small note.

### 2.4 Background

1. Remove the decorative quarter circles from slides 3 to 15 and 17 to 19.
2. Keep decorative shapes only on slides 1, 16 and 20.
3. Make sure that no decorative shape is behind text.
