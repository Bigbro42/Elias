1. Use slide 2 as the model for all slides.

## 1. The style system: only three building blocks

### 1.1 Building block A – pictogram circle (as on slide 2)

| Type | Look | Use |
|---|---|---|
| Light circle | Fill #E3EBEC, Navy line icon | Context, inherited, neutral |
| Teal circle | Fill Teal #1D7874, white line icon | Strength, solution, created |
| Orange ring | No fill, orange outline 2 pt, Navy icon | Weak point, gap, watch point |

1. Use three sizes only: small 1.6 cm, medium 2.6 cm, large 4.0 cm.
2. Put one icon in each circle. Put a short label below the circle.
3. Use one icon family on all slides: thin lines, round line ends, simple shapes.
4. The icons can be friendly and a little playful, as on slide 2. Do not use photos or 3D.

### 1.2 Building block B – thin-rule list (as in the original deck, slide 2)

1. Put a thin line (0.75 pt, Navy) above each item. Use Teal or Orange for a highlighted item.
2. Below the line: label in bold, 14–16 pt.
3. Below the label: one short line, 12–13 pt.
4. Do not put a box, a border or a shadow around the item.

### 1.3 Building block C – connector

1. Connect elements with one thin line or one arrow, as on slide 2.
2. Use one connector type on each slide.

### 1.4 General rules

1. Remove all cards, boxes, borders and shadows from the content slides.
2. Remove all filled dark panels from the content slides. Exception: slides 1, 16 and 20.
3. Make figures 28–36 pt. Use a larger size only for a single key figure.
4. Keep the grid and the vertical balance from prompt v9 (content block in the vertical centre, equal spaces).
5. Keep one takeaway line on each content slide. Keep the source line on each slide with data.
6. Use a lot of white space.

### 1.5 Icon specification

1. Use the style of an open-source line icon set, for example Lucide or Phosphor (style "regular").
2. Use the same set for all slides.
3. Line width: 1.5 pt for small circles, 2 pt for medium and large circles.
4. Put the icon in the centre of the circle. Make the icon 50 % of the circle diameter.
5. On dark slides (1, 16, 20), use white icons.

### 1.7 Focus and quantity

1. Give each slide one focal point. The focal point is the largest element or the only element in Orange. Examples: slide 12 = demand ring, slide 17 = gate 5, slide 4 = the two group headings.
2. Use a maximum of 6 pictogram circles on a slide. Exceptions: slide 8 (5 phases + 0), slide 17 (6 gates + 3), slide 18 (6 actors).
3. Do not put pictograms on slides 3 and 5 if the chart becomes less clear. The charts are more important than the icons.
4. Labels below circles: maximum 4 words, lowercase except names, no full stop.

### 1.8 Animation (optional)

1. Use only "fade in, on click".
2. Use animation only on slides 2, 12, 17 and 20.
3. Slide 17: show gates 1 to 6 one after the other. Show gate 5 last.
